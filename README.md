# Portfolio - Mohammed Aymane Saber

![Portfolio Preview](preview.png)

## 🎯 Overview

Engineering-oriented portfolio showcasing software development projects, technical skills, and professional approach to building applications.

**Not just another portfolio** - This is a technical demonstration of clean architecture, modern tooling, and engineering mindset.

## 🚀 Built With

- **React** - UI library for building the interface
- **Vite** - Next-generation build tool for blazing-fast development
- **Tailwind CSS** - Utility-first CSS framework for custom styling
- **Framer Motion** - Production-ready animation library

## 🏗️ Project Structure

```
portfolio/
├── src/
│   ├── components/        # React components
│   │   ├── Header.jsx     # Navigation header
│   │   ├── Hero.jsx       # Landing section
│   │   ├── About.jsx      # About section
│   │   ├── Skills.jsx     # Technical skills
│   │   ├── Projects.jsx   # Project showcase
│   │   ├── HowIBuild.jsx  # Development process
│   │   ├── Contact.jsx    # Contact information
│   │   └── Footer.jsx     # Site footer
│   ├── App.jsx            # Main app component
│   ├── main.jsx           # Entry point
│   └── index.css          # Global styles + Tailwind
├── public/                # Static assets
├── index.html             # HTML template
└── vite.config.js         # Vite configuration
```

## 🛠️ Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 📝 Customization

1. **Personal Information**: Update name, links, and contact info in components
2. **Projects**: Edit `src/components/Projects.jsx` with your real projects
3. **Skills**: Modify `src/components/Skills.jsx` to match your tech stack
4. **Colors**: Customize theme in `tailwind.config.js`

## 🎨 Design Principles

- **Engineering-first**: Technical focus, not design-heavy
- **Performance**: Optimized bundle size, lazy loading where needed
- **Accessibility**: Semantic HTML, keyboard navigation
- **SEO**: Meta tags, proper heading structure
- **Mobile-first**: Responsive design from smallest to largest screens

## 📦 Deployment

This project can be deployed to:
- **Vercel** (recommended for Vite projects)
- **Netlify**
- **GitHub Pages**
- **Azure Static Web Apps**

```bash
# Build production bundle
npm run build

# The 'dist' folder contains the static files ready for deployment
```
