# Portfolio Website

## Features
- Responsive design
- Smooth animations
- Sections: Hero, About, Projects, Skills, Contact, Footer

## Tech Stack
- Next.js
- Bootstrap
- Framer Motion (optional for advanced animations)

## Getting Started
1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) to view your portfolio.

## Deployment
Deploy easily to Vercel for free.
